# Wayfinder research records

These are dated research records, retrieved as inputs to the generation C
foundation and version-line questions. Each records what first-party sources
said on its retrieval date. They are not current validation evidence: nothing
here was built, deployed, installed, or live-validated as part of the
research.

Generation C's version line is selected in
[#105](https://github.com/nisavid/arch-strix-halo-pkgs/issues/105) within the
2026-09-22 frozen version universe, and recorded in
[c-line-selection-2026-09-22.md](c-line-selection-2026-09-22.md). Where the
2026-08-11 records and that selection disagree, the selection wins.
